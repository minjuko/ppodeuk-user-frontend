## 현재 상태

- 프론트엔드 데모는 기본 포트 `5173`에서 동작하고, 데모 빌드 미리보기는 `4173`을 사용한다. 포트 충돌 시 Vite가 다른 포트로 이동하지 않도록 `strictPort`를 설정했다.
- Mock 데모의 로그인부터 예약 내역 확인까지 브라우저 흐름을 확인했다. MSW 시작 실패 안내, 데모 계정 정리, 임시 screenshot mode 제거도 반영됐다.
- Lint, 106개 프론트엔드 테스트, 운영 빌드, 데모 빌드 및 GitHub Actions CI가 통과했다.
- 백엔드 테스트 태스크는 통과했지만 로컬 실연동 브라우저 검증은 완료되지 않았다. 백엔드가 MariaDB 사용자 인증 거부로 시작되지 않았다. 자격 증명이나 DB를 변경하지 않았으며, `scripts/seed-local.sql`도 실행하지 않았다.
- 프로덕션 의존성 감사는 취약점 0건. 개발 의존성 취약점은 별도 위험으로 남아 있다.

## 다음 작업 우선순위

### 1. 로컬 프론트·백엔드 실연동

- [ ] 로컬 MariaDB 계정/권한과 백엔드 `LOCAL_DB_*` 환경변수 이름을 확인한다. 비밀번호·키를 터미널 출력, 문서, Git에 남기지 않는다.
- [ ] DB 인증이 정상화된 뒤에만 `scripts/seed-local.sql`의 영향과 대상 DB를 먼저 검토하고, 필요한 경우 사용자 확인 후 로컬 전용 DB에 적용한다. 이 스크립트는 테스트 예약 데이터를 초기화할 수 있다.
- [ ] 백엔드 `local` 프로필을 `localhost:8080`에서 실행한다.
- [ ] USER 프론트 `.env`에서 `VITE_API_BASE_URL=http://localhost:8080`, `VITE_DEMO_MODE=false`로 실행한다. Kakao 등록 도메인을 위해 프론트는 `localhost:5173`을 유지한다.
- [ ] 로그인, 토큰 발급/갱신, Bay 및 시간 선택, 로컬 모의 결제, 예약 생성과 내역 반영을 실제 브라우저에서 확인한다. 운영 결제는 시도하지 않는다.
- [ ] 브라우저 콘솔·네트워크 응답에서 인증/ CORS / API 오류를 구분해 기록한다. 실패 시 원인 확인 전 DB나 예약 로직을 수정하지 않는다.

### 2. 비로그인 사용자 흐름 및 모달

- [ ] 로그아웃 상태에서 홈, 목록, 상세 페이지 및 예약 진입 동작을 확인한다.
- [ ] 인증이 필요한 각 동작에서 로그인 페이지 이동, 로그인 유도 모달 또는 차단 처리 중 현재 코드가 의도한 동작을 확인한다. 동작이 화면/라우트별로 일관적인지 기록한다.
- [ ] 로그인 유도 모달의 열기/닫기, 바깥 클릭·ESC 동작, 모바일 레이아웃, 로그인 이후 원래 작업으로 복귀 여부를 확인한다.
- [ ] 만료/잘못된 토큰, 로그인 API 실패, 중복 모달, 뒤로 가기 동작을 확인한다. 예상과 실제가 다를 때 재현 절차와 화면/네트워크 증거를 남긴다.
- [ ] 재현 가능한 결함만 최소 수정하고 관련 테스트를 추가한다. 인증·예약 동작을 가정에 따라 바꾸지 않는다.

### 3. 배포 상태 검증

- [ ] 현재 배포 URL과 실제 배포 커밋을 확인한다. 배포가 최신이 아니라면 상태를 먼저 기록하고 임의로 배포 설정을 변경하지 않는다.
- [ ] 배포 화면의 비로그인 진입, 로그인/데모 안내, 모달, 목록·상세 이미지 및 반응형 레이아웃을 점검한다.
- [ ] 네트워크에서 API URL, 이미지 응답 상태, Kakao 지도 로딩을 확인한다. 브라우저 콘솔 오류와 mixed-content/CORS 문제를 기록한다.
- [ ] 배포 환경에서 운영 결제나 실제 사용자 데이터 변경은 하지 않는다. 검증 계정/샌드박스가 확인된 경우에만 허용된 범위에서 테스트한다.
- [ ] 최종적으로 lint, 전체 테스트, 운영 빌드, `npm run build:demo:local`을 다시 실행하고 diff를 검토한다.

## 실행 메모

```powershell
# 프론트엔드 Mock 데모 (5173)
npm run dev:mock

# 데모 빌드 검증 (4173)
npm run build:demo:local
npm run preview:demo

# 백엔드 local 프로필은 별도 터미널에서 실행
./gradlew.bat bootRun --args='--spring.profiles.active=local'

# 프론트엔드 검증
npm run lint
npm test
npm run build
npm run build:demo:local
```
