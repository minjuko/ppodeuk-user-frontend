# 추천 세차장 조회 장애 해결 기록 (2026-10-15)

## 문제 상황

- 로그인 전 홈 화면에서 추천 세차장 조회가 실패했고, 브라우저 네트워크 탭에는 요청이 `취소됨`으로 표시됐다.
- 장애 중에는 추천 카드가 보이지 않거나 오류 문구가 노출됐다.
- 공개 사이트 상단에는 제출용 화면에 불필요한 `Portfolio Demo` 문구가 표시됐다.
- 공개 배포가 모의 백엔드(MSW)를 사용하는 데모 빌드로 설정되어 있어 실제 백엔드와 로컬 검증 환경이 분리되지 않았다.

## 원인 확인

- API를 직접 호출하자 약 10초 뒤 HTTP 500 응답이 돌아왔다. 응답에는 `JDBCConnectionException: could not extract ResultSet`가 포함됐다.
- Railway 백엔드 로그에는 MySQL 오류 1053, 연결 상태 `08S01`, `Server shutdown in progress`가 기록됐고, 추천 세차장 조회 서비스가 실행 중이었다.
- 프런트엔드 요청 제한시간은 5초다. 서버 오류가 돌아오기 전에 브라우저가 요청을 끊어 네트워크 탭에 `취소됨`으로 보일 수 있었다. 이 표시는 HTTP 응답 코드가 아니다.
- 따라서 좌표나 로그인 권한이 주원인이라기보다 백엔드와 데이터베이스 사이의 연결 중단이 직접 원인으로 확인됐다. 데이터베이스가 종료된 근본 사유는 Railway 측 로그·수명주기 확인이 더 필요하다.
- Vercel 배포 목록에서는 최신 배포가 준비 완료였지만, 공개 주소가 이전 화면을 보인 시점이 있었다. 새 배포 주소와 공개 주소의 표시가 달라 캐시 또는 배포 전파 문제를 의심했다. 기존 MSW와 서비스워커가 함께 실행되면 동일 범위를 두고 충돌할 수 있어, 데모 빌드에 PWA 서비스워커를 추가하는 시도는 되돌렸다.

## 해결 방법

- 추천 API 응답이 아직 없거나 실패해도 로컬 예시 추천 카드를 즉시 보여주도록 했다. 실제 응답이 도착하면 해당 데이터로 교체한다.
- API가 실패해 예시 카드를 보여줄 때는 예시임을 알리는 문구를 함께 표시한다.
- Vercel 빌드를 데모 빌드에서 일반 프로덕션 빌드로 바꾸고, 산출물 경로도 `dist-demo`에서 `dist`로 변경한다. 공개 배포는 MSW를 시작하지 않고 Vercel의 `VITE_API_BASE_URL` 설정으로 실제 백엔드에 연결한다.
- MSW 실행은 `npm run dev:mock`으로만 제공해, 백엔드 없이 프런트엔드 단독으로 확인할 때 사용할 수 있게 분리한다. 로컬 모의용 빌드는 `npm run build:demo:local`로 이름을 구분한다.
- 로그인 화면의 데모 계정 안내·자동 입력 UI는 모의 모드에서만 보이게 했다. 일반 프로덕션 빌드에서는 노출하지 않는다.
- 상단 `Portfolio Demo` 안내는 데모 빌드에서만 렌더링된다. 공개 사이트는 일반 빌드를 사용하므로 표시되지 않는다.

## 검증 결과

- 추천 세차장 컴포넌트 테스트에서 요청 대기 중과 API 실패 상태 모두 기본 예시 카드가 표시되는 것을 확인했다.
- lint와 Vercel 설정에 맞춘 프로덕션 빌드를 확인한다.
- Vercel 환경 변수에서 `VITE_API_BASE_URL`은 기존 Production 설정을 사용한다. 데모 모드·화면 캡처 모드 변수는 Production에서 제거해 로컬 전용 설정으로 남긴다.
- Vercel 배포 완료 후 공개 주소에서 추천 카드와 이미지, 로그인 화면의 데모 계정 UI 미노출, 상단 데모 문구 미노출을 확인한다.

## 결과와 남은 작업

- 비로그인 사용자는 백엔드 지연·실패 상황에서도 홈 화면의 추천 카드 영역을 볼 수 있다.
- 공개 배포에서 MSW를 실행하지 않도록 빌드 경로를 분리한다. 프런트엔드만 실행하는 로컬 검증에서만 MSW를 사용한다.
- DB 연결 중단은 프런트엔드 변경으로 복구되지 않는다. Railway의 MySQL 종료·재시작 시점과 백엔드 연결 풀 상태를 확인해야 한다. 상시 실행 설정은 비용이 발생할 수 있어 별도 검토 없이 변경하지 않는다.
- 기존 브라우저가 이전 서비스워커 캐시를 보유하는 경우까지 포함해 공개 주소 갱신을 재검증한다.
